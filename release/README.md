# ySBGN 1.2.0

Ready-to-run jars, built from branch `java-modern` (commit 2ca4a9e). Java 11 or newer
is needed (https://adoptium.net); JavaFX is included.

| Your computer | File |
|---|---|
| Mac with Apple chip (M1 and later) | `ySBGN-1.2.0-mac-arm.jar` |
| Mac with Intel chip | `ySBGN-1.2.0-mac-intel.jar` |
| Windows | `ySBGN-1.2.0-windows.jar` |
| Linux | `ySBGN-1.2.0-linux.jar` |

Double-click the jar to open the window, or convert from the command line (any of the four
jars):

    java -jar ySBGN-1.2.0-linux.jar map.graphml [map.sbgn]
    java -jar ySBGN-1.2.0-linux.jar map.sbgn [map.graphml]
